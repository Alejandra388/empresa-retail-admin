## empresa-retail-admin

> Proyecto final: sistema de administración de base de datos para una empresa de retail.

##  Descripción

Este proyecto contiene la implementación y administración de la base de datos **empresa_retail**, incluyendo el modelo relacional, la gestión de usuarios y permisos, la automatización de procesos mediante procedimientos almacenados y la validación del correcto funcionamiento de la solución.

## 📂 Contenido del proyecto

| Componente | Descripción |
|---|---|
|  **Modelo relacional** | Diseño de las tablas de la base de datos empresa retail y sus relaciones. |
|  **Usuarios y permisos** | Script para la creación de usuarios y la asignación de privilegios según sus roles. |
|  **Procedimiento almacenado** | Script de un procedimiento almacenado para la tabla `conversion`. |
|  **Validación** | Script para comprobar que la estructura, los permisos y el procedimiento funcionan correctamente. |

## Cómo usar

1. Clonar el repositorio:
```bash
   git clone https://github.com/TU_USUARIO/empresa-retail-admin.git
```
2. Cambiar a la rama de desarrollo:
```bash
   git checkout develop
```
3. Ejecutar los scripts en el gestor de base de datos en este orden:
   1. Modelo relacional
   2. Usuarios y permisos
   3. Procedimiento almacenado
   4. Validación

## Ramas

- **main**: rama principal.
- **develop**: rama de desarrollo donde se encuentra la solución de la actividad.
